# MeiLinMod 卡牌总结表

说明：
- 表格按当前 C# 卡牌定义与 `MeiLinMod/localization/zhs/cards.json` 生成。
- 格式参考 `YukiMod/docs/yuki-card-table.zh-CN.md`，列为“名称/费用/稀有度/种类/效果/流派”，额外保留“卡池”方便区分主卡池与衍生/隐藏牌。
- `a/b` 表示基础/升级后数值；`X费` 表示 X 费用。
- 流派按文本关键词归类，一张牌可同时属于多个流派，所以流派统计会重复计数。
- `消耗`、`固有`、`保留` 等通用关键词来自代码中的 `CardKeyword`，表格中只作效果记录。

- 基本功：围绕打击、防御、费用变为 0、重放、生成和本场战斗成长。

- 余烬：施加、翻倍、延迟或改变余烬衰减，并围绕炎龙/火龙收益扩展。
- 香族：角色核心遗物/精神相关的临时力量与姿态体系。
