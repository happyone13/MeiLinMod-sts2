# 梅铃与友纪表现层优化记录

日期：2026-11-14 至 2026-11-15。目标游戏：0.113。发布版本：MeiLinMod 0.4.8、YukiMod 0.1.9。本轮仅修改这两个 Mod。

## 改动

1. 战斗深度预热延后两帧检查实际参战角色。没有对应角色时，不枚举和实例化该角色的预热特效。每次进入房间都会使旧预热任务失效，异步等待后重新检查房间与代次。
2. 动态卡面检测隐藏、透明、屏幕范围及祖先 Control 裁剪范围。不可见时同时关闭 SubViewport 渲染与节点处理；再次可见时恢复原 ProcessMode 和持续渲染。可见卡面保持动画。
3. 普通一次性特效按原父节点和资源路径建立实例缓存，梅铃额外区分动画，每种效果最多保留两个空闲实例。播放中的实例不受此上限限制，不会丢弃可见特效。
4. 角色场景新增 ModelRoot，只放 Spine、CenterPos 和模型特效锚点。攻击、瞬移、空中阶段、回位与胜利恢复均移动 ModelRoot；NCreature、Bounds、血条、Buff、意图及对话锚点保持原位置。模型自己的 Z 层单独提升和恢复，不再调整整个角色的兄弟顺序。
5. 梅铃 TalkPos 改到右上方；友纪实际使用的 chaos_yuki.tscn 原本没有 TalkPos，新增右上方锚点，同时同步备用角色场景。位置取 Bounds 右侧 20 像素、顶部。
6. UG/UX 增加首绘屏障：不借用实战模型、不播放声音、不推进时钟，先以 0.001 透明度绘制角色与预建特效两帧，提交首张 cut-in 纹理；随后暂停骨骼、隐藏节点并复位透明度，正式 begin 后才绑定模型、声音与演出时钟。等待后检查房间和开关，取消走原来的无演出回调。
7. 角色专属资源预载从 Mod 初始化移至该角色创建战斗模型时，成功后每进程执行一次。关闭对应功能时不预载该功能，运行时仍保留按需加载。共享 Gloomy 预载保留原有归属。

实例回收时隐藏并暂停处理，解绑本次播放注册的 Spine 完成回调，停止粒子发射。复用时恢复根节点变换、透明度、层级及初始可见状态。梅铃额外移除运行时添加的跟随节点。

Spine 节点与 MegaSprite 包装器在实例创建时缓存，不再通过对每个普通节点构造 MegaSprite 并捕获异常来识别骨骼。完成回调与延迟播放都检查播放代次，旧任务不能结束已经复用的新播放。

友纪两个 PlaySpineOneShot 重载保留签名并共用实现。战斗预热实例按正式播放的前后容器进入同一普通特效缓存，不再用固定的 animation 缓存键隔开 eff_b/eff_f 播放。预热必须找到可播放动画，否则明确记为失败。

持续光环与 CreatureAbove/CreatureBelow 跟随特效挂到模型层；CenterPos 随模型移动，普通命中和投射物仍通过原版 VfxSpawnPosition 获取正确世界坐标。

## 收益范围与代价

- 卡面优化消除不可见卡面的持续骨骼更新与离屏渲染。可见手牌不降低动画帧率或分辨率。
- 缓存主要减少同一战斗中重复出现的小特效实例化、节点遍历与包装器创建。代价是保留少量空闲实例及其资源引用，房间或所属父节点销毁时一并释放。
- 梅铃移动特效使用长期存活的战斗容器，可以跨次移动复用。命令时间轴仍使用临时父节点，复用范围受该父节点生命周期限制；预热阶段不为这些命令长期保留无法跨时间轴复用的实例。
- UG/UX 保留现有舞台、事件和命中时间轴，只增加开播前的准备阶段；未修改伤害结算规则。
- 首绘准备增加两帧开播等待，减少构造和首次绘制挤占正式演出时钟；它不是零开销，也不保证所有延迟粒子或后续视频帧都已完成 GPU 首绘。
- 角色预载在实际创建模型时执行，战斗实例预热仍逐项进行，每项准备后让出帧，最多一项在途。

## 后续其他 Mod 可复用的规则

1. 移动表现层之前先查原版 UpdateBounds。只换成移动 NCreatureVisuals，仍可能让后续 BoundsUpdated 带动血条；使用独立模型层，保持 Bounds/IntentPos/OrbPos/TalkPos 的坐标系稳定。
2. 改场景父子关系后检查所有直接节点路径、unique_name_in_owner、CenterPos、脚底标记、持续光环、跟随 VFX 与回位分支。
3. 资源缓存和实例预热要区分：预热的父节点和缓存键必须与正式播放一致，否则会保留无法复用的实例。
4. 首绘阶段必须发生实际渲染，不能只 Hide；音频、命中和演出时钟均从准备完成后开始。取消应先恢复准备状态，再执行一次无演出玩法路径。
5. UI 位移测试先等待原版入场 Tween，否则会把 UI 自身缓动误判成模型牵连。使用真实血条和至少一个真实 Buff 图标验证。
6. 演出截图按舞台自己的时钟采样，并检查非单色画面；不要跳过时间戳，骨骼与粒子仍需要实际处理帧。
