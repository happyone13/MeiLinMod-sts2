# 重放时的角色动画

修复发布版本：梅铃 `v0.4.6`。

- 同一次出牌中，只有 `CardPlay.PlayIndex == 0` 播放角色攻击、施法、背身立绘及 UG/UX 演出。后续重放保留伤害、格挡、能力与目标命中反馈。
- 使用原生 `CurrentPlayIndex`，不按卡牌 ID、回合或静态集合去重。再次打出同一张牌仍正常播放动画。
- `MeiLinReplayVisuals` 在原生 `CardModel.OnPlayWrapper` 的异步上下文中跟踪当前卡牌；调用方的上下文即时恢复，自动打出的其他卡牌使用各自的出牌上下文。
- 跳过 UG/UX 时立即执行一次 `onHit(false)`。攻击命令仍按原规则结算，仅关闭重复的施法者动作；多段攻击第一次出牌的动作保持原样。
- 重放不向多段攻击动画队列写入任务，不重复播放配套出牌音效，也不累加下一次默认音效的抑制计数。
- `ReplayAnimationTests` 覆盖伤害次数、异步上下文、重复手动出牌及重放神:攻防一体时子卡牌的独立动画。
